# Task Break Agent Guide

`About\About.xml` is authoritative for package identity; do not infer it from
the repository folder name.

Never draft/undraft, clear job queues, or bypass
`IsCurrentJobPlayerInterruptible`. Medical, birth, caravan, ritual, quest,
mental-state, deathrest, and other protected work fails closed.

Keep the ordinary RimWorld key binding rebindable through native controls; do
not add global polling or mouse adapters. Render its assigned label in the
gizmo's top-left and place the gizmo at the far right.

Use `SpineMod<TaskBreakSettings>` and Spine's patching/contextual contracts.
Metadata, `Tools\CascadeManifest.json`, project files, and `Tests` are the local
support and verification authorities. Follow
`A:\Dev\RimWorld\AGENTS.md` for shared build/runtime work.
